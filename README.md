# Case Inventory Tracker

A simple web app to track CS:GO case quantities with a change log.

## Features

- ✅ Add/subtract quantities with +/- buttons
- 📝 Automatic change log
- 💾 Data persists locally (no login required)
- 🎨 Clean, modern UI

## Deploy to Vercel

1. Install Vercel CLI: `npm i -g vercel`
2. Run: `vercel`
3. Follow the prompts

Or use the Vercel dashboard:
1. Go to https://vercel.com
2. Click "Add New Project"
3. Import this Git repository
4. Deploy!

## Local Testing

Just open `index.html` in your browser - it works immediately!

## How It Works

All data is stored in your browser's localStorage. No backend needed!
